🚀 Getting Started

  • Base URL: http://localhost:8000/api/
  • Authentication: JWT Bearer Token required for all protected endpoints
  • Content Type: application/json for most APIs
  • File Uploads: multipart/form-data for document uploads
  • Response Format: Consistent JSON format with success/error indicators

🔐 Authentication

All APIs require JWT authentication. Include the Bearer token in the Authorization header.

Header Format:

Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc...

Python Example:

headers = {
    'Authorization': f'Bearer {your_jwt_token}',
    'Content-Type': 'application/json'
}

response = requests.get(url, headers=headers)

JavaScript Example:

const headers = {
    'Authorization': `Bearer ${yourJwtToken}`,
    'Content-Type': 'application/json'
};

const response = await fetch(url, { headers });

⚠️ Important Notes

Date Format: Always use YYYY-MM-DD format

Time Format: Use HH:MM:SS format for time fields

Decimal Values: Use decimal format for hours (e.g., 3.5 for 3 hours 30 minutes)

File Uploads: Use multipart/form-data for document uploads

Error Handling: Check response status and error messages for troubleshooting
