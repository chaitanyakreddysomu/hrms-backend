📊 Overview

The HR Dashboard APIs provide comprehensive HR management capabilities including real-time statistics, attendance tracking, salary management, payslip generation, overtime management, and advanced analytics.

📱 Bulk Operations Support

🔐 Access Control - STRICT ROLE-BASED

Who can access: HR Role ONLY ✅
Blocked Roles: Admin, Manager, Sub-Manager, Supervisor, Employee ❌
Authentication: JWT Bearer Token required for all endpoints
Permission Class: IsHROnly
Base URL: http://localhost:8000/api/hr-dashboard/

📊 Dashboard Statistics

GET
/api/hr-dashboard/dashboard-stats/

Get comprehensive dashboard statistics

Query Parameters (All Optional):

company_id: 5
month: 10
year: 2024

Response (200 OK):

{

  "data": {
    "employees": {

      "active": 145,
      "inactive": 5,

      "statistics": {
        "present": 2800,
        "absent": 120,
        "weekly_off": 600,
        "holiday": 150,
        "half_day": 30
      },
      "total_records": 3700

Python Example:

import requests

url = 'http://localhost:8000/api/hr-dashboard/dashboard-stats/'
headers = {'Authorization': f'Bearer {hr_token}'}
params = {'company_id': 5, 'month': 10, 'year': 2024}

response = requests.get(url, headers=headers, params=params)
stats = response.json()['data']

print(f"Total Employees: {stats['employees']['total']}")
print(f"Active: {stats['employees']['active']}")
print(f"Total Payroll: ₹{stats['salary']['total_payroll']:,.2f}")

JavaScript Example:

const params = new URLSearchParams({
  company_id: 5,
  month: 10,
  year: 2024
});

const response = await fetch(
  `http://localhost:8000/api/hr-dashboard/dashboard-stats/?${params}`,
  { headers: { 'Authorization': `Bearer ${hrToken}` } }
);

const { data } = await response.json();
console.log('Dashboard Stats:', data);

👥 Attendance Management

POST
/api/hr-dashboard/mark-attendance/

Mark attendance for an employee

Request Body:

{
  "employee_id": 1,
  "date": "2024-10-07",
  "status": "P"
}

Status Values:

  • P - Present
  • A - Absent
  • WO - Weekly Off
  • H - Holiday
  • HD - Half Day

Response (201 Created):

{
  "success": true,
  "message": "Attendance marked successfully",
  "data": {
    "id": 1,
    "employee": 1,
    "date": "2024-10-07",
    "status": "P"
  }
}

Python Example:

response = requests.post(
    'http://localhost:8000/api/hr-dashboard/mark-attendance/',
    headers={'Authorization': f'Bearer {hr_token}'},
    json={
        'employee_id': 1,
        'date': '2024-10-07',
        'status': 'P'
    }
)
print(response.json()['message'])
POST
/api/hr-dashboard/bulk-mark-attendance/

Mark attendance for multiple employees at once

Request Body:

{
  "date": "2024-10-07",
  "attendance_records": [
    {"employee_id": 1, "status": "P"},
    {"employee_id": 2, "status": "A"},
    {"employee_id": 3, "status": "P"},
    {"employee_id": 4, "status": "HD"}
  ]
}

Response (200 OK):

{
  "success": true,
  "message": "Bulk attendance marking completed",
  "summary": {
    "created": 2,
    "updated": 2,
    "errors": 0
  },
  "errors": null
}

JavaScript Example:

const attendanceData = {
  date: '2024-10-07',
  attendance_records: [
    {employee_id: 1, status: 'P'},
    {employee_id: 2, status: 'A'},
    {employee_id: 3, status: 'P'}
  ]
};

const response = await fetch(
  'http://localhost:8000/api/hr-dashboard/bulk-mark-attendance/',
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${hrToken}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(attendanceData)
  }
);

const result = await response.json();
console.log(`Created: ${result.summary.created}, Updated: ${result.summary.updated}`);

📄 Payslip Management

POST
/api/hr-dashboard/generate-payslip/

Generate PDF payslip for an employee

Request Body:

{

  "month": 10,
  "year": 2024,
  "working_days": 26,
  "days_present": 24,

🔄 Employee Status Management

PUT
/api/hr-dashboard/update-employee-status/

Update employee status (ACTIVE, LEFT, TERMINATED)

Request Body:

{
  "employee_id": 1,
  "status": "LEFT",
  "remarks": "Resigned for better opportunity"
}

Valid Status Values:

  • ACTIVE - Currently working
  • LEFT - Resigned/Left the company
  • TERMINATED - Terminated by company

  "data": {
    "employee_id": 1,
    "employee_name": "John Doe",

Python Example:

response = requests.put(

        'status': 'LEFT',
        'remarks': 'Resigned'

)

result = response.json()

🔐 Authentication

JWT Token Authentication

All HR Dashboard APIs require JWT authentication. Include the Bearer token in the Authorization header.

How to Include Token:

Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc...

Python Example:

headers = {
    'Authorization': f'Bearer {your_jwt_token}',
    'Content-Type': 'application/json'
}

response = requests.get(
    'http://localhost:8000/api/hr-dashboard/dashboard-stats/',
    headers=headers
)

JavaScript Example:

const headers = {
    'Authorization': `Bearer ${yourJwtToken}`,
    'Content-Type': 'application/json'
};

const response = await fetch(
    'http://localhost:8000/api/hr-dashboard/dashboard-stats/',
    { headers }
);

cURL Example:

curl -X GET "http://localhost:8000/api/hr-dashboard/dashboard-stats/" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -H "Content-Type: application/json"

⚠️ Important Notes

  • Date Format: Always use YYYY-MM-DD format for dates
  • Decimal Values: Use decimal format for hours (e.g., 3.5 for 3 hours 30 minutes)
  • Salary Components: All salary amounts should be annual figures
  • Pro-rated Calculations: Payslips automatically calculate pro-rated salaries based on attendance
  • Increment History: Automatically recorded when CTC changes in salary structure
  • PDF Generation: Payslips generate PDF files automatically, stored in media/payslips/
  • Company Filtering: Use company_id to filter data for specific companies/sub-companies
  • Bulk Operations: Use bulk APIs for better performance when handling multiple records
