🏢 Manager Dashboard APIs

Complete API Documentation for Main Company Management

REST API Django REST Framework Manager Role Main Company

🔒 MANAGER ROLE REQUIRED - STRICT ACCESS CONTROL

⚠️ IMPORTANT: These APIs can ONLY be accessed by users with the "Manager" role.

Any attempt to access these endpoints with a different role (Employee, HR, Supervisor, Sub-Manager, Admin) will result in 403 Forbidden error.

Authentication: Include JWT token in Authorization header: Authorization: Bearer <your_token>

Base URL: /api/manager-dashboard/

Permission Class: IsManager - Verifies user role is exactly "Manager"

🎯 Access Control Summary:
  • ✅ Allowed: Users with "Manager" role assigned to a main company
  • ❌ Denied: Admin, Sub-Manager, HR, Supervisor, Employee, and unauthenticated users
  • 📊 Scope: Manager can access main company data + all sub-companies under their management

🔒 Security & Access Control

⚠️ MANAGER ROLE ONLY

Permission Class: IsManager

Every endpoint in this API is protected by a custom permission class that verifies:

  1. User is authenticated (valid JWT token)
  2. Employee record exists in the database
  3. Employee role is exactly "Manager" (case-sensitive)
  4. Employee is assigned to a main company

Who Can Access?

Role Access Reason
Manager ✅ YES Primary role for main company management
Admin ❌ NO Has separate admin dashboard
Sub-Manager ❌ NO Has separate sub-manager dashboard
HR ❌ NO Has separate HR dashboard
Supervisor ❌ NO Has separate supervisor dashboard
Employee ❌ NO Has separate employee dashboard

Error Responses

No Authentication Token:

HTTP 401 Unauthorized
{
  "detail": "Authentication credentials were not provided."
}

Wrong Role (Not Manager):

HTTP 403 Forbidden
{
  "detail": "You do not have permission to perform this action."
}
💡 Pro Tip: Test your access by calling the company-overview endpoint first. If you get a 403 error, verify your user account has the "Manager" role assigned in the database.

👥 Employee Management

GET /api/manager-dashboard/employees/

Get paginated list of all employees under manager's company (main company and sub-companies).

Query Parameters:

department string optional

Filter by department name

designation string optional

Filter by designation

status string optional

Filter by status (ACTIVE, INACTIVE, LEFT)

company_id integer optional

Filter by specific company ID

include_sub_companies boolean optional

Include sub-company employees. Default: true

search string optional

Search by name, email, or employee code

page integer optional

Page number. Default: 1

page_size integer optional

Items per page. Default: 20

{
  "success": true,
  "data": [
    {
      "id": 1,
      "full_name": "John Doe",
      "employee_code": "EMP001",
      "email": "john@company.com",
      "role": "Employee",
      "status": "ACTIVE",
      ...
    }
  ],
  "pagination": {
    "page": 1,
    "page_size": 20,
    "total": 150,
    "total_pages": 8
  }
}
GET /api/manager-dashboard/employees/{employee_id}/

Get detailed information about a specific employee including profile, official details, salary structure, recent attendance, and payslips.

Path Parameters:

employee_id integer required

Employee ID

📋 Returns: Complete employee profile, official details, salary structure, recent attendance (last 30 days), and recent payslips (last 6 months).

    "recent_attendance": [...],
    "recent_payslips": [...]
  }
}
