Authentication Notes

Authorization Header Format:

Authorization: Bearer <access_token>

Permission Types:

  • Authenticated: Any logged-in user
  • ClientProfile: User must have client profile permission
  • Admin: Super admin users only
  • HR: HR role users
  • Supervisor: Supervisor role users

Common HTTP Status Codes:

  • 200: Success
  • 201: Created
  • 400: Bad Request
  • 401: Unauthorized
  • 403: Forbidden
  • 404: Not Found
  • 500: Internal Server Error

Base URL:

https://your-domain.com/

Content-Type Header:

Content-Type: application/json
