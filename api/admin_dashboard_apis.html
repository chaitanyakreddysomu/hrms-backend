⚡ Admin Dashboard APIs

Complete System Management & Administration

REST API Django REST Framework Admin Role ONLY System-Wide Access

🔒 ADMIN ROLE REQUIRED - HIGHEST SECURITY LEVEL

⚠️ CRITICAL: These APIs can ONLY be accessed by users with the "Admin" role.

Admin has complete system-wide access to all companies, all employees, and all data across the entire HRMS.

Authentication: Include JWT token in Authorization header: Authorization: Bearer <your_token>

Base URL: /api/admin-dashboard/

Permission Class: IsAdmin - Verifies user role is exactly "Admin"

🎯 Access Control Summary:
  • ✅ Allowed: Users with "Admin" role only
  • ❌ Denied: Manager, Sub-Manager, HR, Supervisor, Employee, and unauthenticated users
  • 📊 Scope: Complete system-wide access to ALL companies, ALL employees, ALL data
  • 🔐 Security: Highest privilege level in the system

🔒 Security & Access Control

⚠️ ADMIN ROLE ONLY - HIGHEST PRIVILEGE

Permission Class: IsAdmin

Every endpoint in this API is protected by a custom permission class that verifies:

  1. User is authenticated (valid JWT token)
  2. Employee record exists in the database
  3. Employee role is exactly "Admin" (case-sensitive)

Who Can Access?

Role Access Dashboard
Admin ✅ YES THIS API - Complete system access
Manager ❌ NO /api/manager-dashboard/
Sub-Manager ❌ NO /api/sub-manager-dashboard/

Supervisor ❌ NO /api/supervisor-dashboard/

💡 Important: Admin role has the highest privilege level and complete access to ALL system resources. Use with extreme caution and ensure proper authentication.

🏢 Company Management

GET /api/admin-dashboard/companies/

Get list of all companies (both main and sub-companies) with employee counts and statistics.

Query Parameters:

is_main_company boolean optional

Filter by company type (true for main companies, false for sub-companies)

search string optional

Search by company name

page integer optional

Page number. Default: 1

page_size integer optional

Items per page. Default: 20

}

👥 Employee Management

GET /api/admin-dashboard/employees/

Get list of ALL employees across ALL companies in the entire system with advanced filtering options.

Query Parameters:

company_id integer optional

Filter by specific company

department string optional

Filter by department

designation string optional

Filter by designation

role string optional

Filter by role (Admin, Manager, Sub-Manager, HR, Supervisor, Employee)

status string optional

Filter by status (ACTIVE, INACTIVE, LEFT)

search string optional

Search by name, email, or employee code

page integer optional

Page number. Default: 1

page_size integer optional

Items per page. Default: 50

GET /api/admin-dashboard/employees/{employee_id}/

Get complete detailed information about ANY employee in the system including profile, official details, salary, attendance history, payslips, and documents.

Path Parameters:

employee_id integer required

Employee ID

📋 Returns: Complete employee information including personal details, official details, salary structure, recent attendance (last 30 days), recent payslips (last 6 months), and document count.
