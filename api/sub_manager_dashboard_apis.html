📚 API Endpoints

🏢 Company Overview

GET Company Overview
/api/sub-manager-dashboard/company-overview/

Get comprehensive overview of sub-company with statistics, employee counts, attendance, overtime, and salary data.

Query Parameters: month (optional), year (optional)

Response:

{
  "success": true,
  "sub_manager": {...},
  "company": {...},
  "data": {
    "employees": {
      "total": 50,
      "active": 45,
      "by_department": [...],
      "by_designation": [...]
    },
    "attendance": {...},
    "overtime": {...},
    "salary": {...}
  }
}

👥 Employee Management

GET Company Employees
/api/sub-manager-dashboard/company-employees/

Get list of all employees in the sub-company with filtering options.

Query Parameters: department, designation, status (all optional)

GET Employee Details
/api/sub-manager-dashboard/employee-details/?employee_id=12

Get detailed information about a specific employee including salary, attendance, and performance.

Query Parameters: employee_id (required)

📅 Attendance Management

POST Mark Attendance
/api/sub-manager-dashboard/mark-attendance/

Mark attendance for a single employee.

Request Body:

{
  "employee_id": 12,
  "date": "2024-10-07",
  "status": "P"
}

Status Values: P (Present), A (Absent), WO (Weekly Off), H (Holiday), HD (Half Day)

POST Bulk Mark Attendance
/api/sub-manager-dashboard/bulk-mark-attendance/

Mark attendance for multiple employees at once.

Request Body:

{
  "date": "2024-10-07",
  "attendance_records": [
    {"employee_id": 12, "status": "P"},
    {"employee_id": 13, "status": "A"}
  ]
}
GET Attendance Report
/api/sub-manager-dashboard/attendance-report/?start_date=2024-10-01&end_date=2024-10-31

Get detailed attendance report for a date range.

Query Parameters: start_date (required), end_date (required), employee_id (optional)

💰 Salary Management

POST Create Salary Structure
/api/sub-manager-dashboard/create-salary-structure/

Create salary structure for an employee with all components.

Request Body: employee_id, CTC, basic, da, hra, conveyance, bonus, other_allowances, pf_deduction, esi_deduction, pt_deduction, lwf_deduction, insurance, advance

GET Salary Report
/api/sub-manager-dashboard/salary-report/

Get comprehensive salary report for all company employees.

Query Parameters: department (optional)

⏰ Overtime Management

POST Record Overtime
/api/sub-manager-dashboard/record-overtime/

Record overtime hours for an employee.

Request Body:

{
  "employee_id": 12,
  "date": "2024-10-07",
  "hours": 3.5
}
GET Overtime Report
/api/sub-manager-dashboard/overtime-report/?start_date=2024-10-01&end_date=2024-10-31

Get overtime report for all employees in date range.

Query Parameters: start_date (required), end_date (required)

📊 Analytics & Reports

GET Company Analytics
/api/sub-manager-dashboard/company-analytics/

Get comprehensive analytics including headcount, salary analysis, attendance trends, and turnover rates.

Query Parameters: year (optional)

⚡ Quick Actions

GET Today Summary
/api/sub-manager-dashboard/today-summary/

Get today's attendance summary for quick overview of company status.

Response includes: Total employees, present count, absent count, not marked count, and individual employee status
