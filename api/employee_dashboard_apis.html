📊 1. Dashboard APIs

GET
/api/employee-dashboard/stats/
Get dashboard statistics including present days, absent days, OT hours, and take-home salary for current month.
GET
/api/employee-dashboard/notifications/
Get recent notifications. Supports query params: ?limit=10&unread_only=true
POST
/api/employee-dashboard/{id}/mark-read/
Mark a specific notification as read.
POST
/api/employee-dashboard/mark-all-read/
Mark all notifications as read for the current employee.

👤 2. Profile APIs

GET
/api/employee-profile/personal-info/
Get personal information: full name, employee code, DOB, gender, marital status.
GET
/api/employee-profile/contact-info/
Get contact information: mobile number, email, current address, permanent address.
GET
/api/employee-profile/official-info/
Get official information: DOJ, department, designation, location, supervisor name.
GET
/api/employee-profile/identity-docs/
Get identity documents: Aadhaar, PAN, ESI, PF UAN numbers.
GET
/api/employee-profile/bank-info/
Get bank information: bank name, account number, IFSC code, branch name.
GET
/api/employee-profile/complete/
Get complete employee profile in one API call (all sections combined).
POST
/api/employee-profile/request-update/
Submit a request to update profile fields. Requires HR approval.
GET
/api/employee-profile/update-requests/
View all profile update requests and their approval status.

📄 3. Documents APIs

GET
/api/employee-documents/list/
Get list of all documents for the employee.
GET
/api/employee-documents/appointment-order/
Get appointment order document details.
GET
/api/employee-documents/esi-card/
Get ESI card document (if applicable).
GET
/api/employee-documents/id-card/
Get ID card document for download/print.
GET
/api/employee-documents/relieving-letter/
Get relieving letter (for resigned/terminated employees).
GET
/api/employee-documents/{id}/download/
Download any document by its ID as PDF.

💰 4. Salary APIs

GET
/api/employee-salary/structure/
Get complete salary structure with earnings (Basic, DA, HRA, etc.) and deductions (PF, ESI, PT, etc.).
GET
/api/employee-salary/payslips/
Get monthly payslip history. Supports filters: ?year=2024&month=12
GET
/api/employee-salary/{id}/download/
Download payslip PDF for a specific month.
GET
/api/employee-salary/increments/
Get increment history with effective dates and old vs new salary comparison.

📅 5. Attendance APIs

GET
/api/employee-attendance/calendar/
Get monthly attendance calendar view. Supports: ?year=2025&month=1
GET
/api/employee-attendance/summary/
Get attendance summary table with total working days, present, absent, weekly offs, holidays, and overtime.
GET
/api/employee-attendance/overtime/
Get overtime details for a specific month with date-wise hours.

Attendance Status Codes:

P Present
A Absent
WO Weekly Off
H Holiday
HD Half Day

📊 6. Reports APIs

GET
/api/employee-reports/list/
Get list of all generated reports for the employee.
GET
/api/employee-reports/salary-statement/
Get yearly/quarterly salary statement report.
GET
/api/employee-reports/deduction-statement/
Get deduction statement for PF, ESI, PT, LWF contributions.
GET
/api/employee-reports/{id}/download/
Download any report by its ID as PDF.
