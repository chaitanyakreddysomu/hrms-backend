Query Parameters (All Optional):

Response (200 OK):

      "by_department": [
        {"officialdetails__department": "Operations", "count": 10},
        {"officialdetails__department": "Support", "count": 5}
      ],
      "by_designation": [
        {"officialdetails__designation": "Team Lead", "count": 3},
        {"officialdetails__designation": "Associate", "count": 12}
      ]
    },
    "attendance": {
      "month": 10,
      "year": 2024,
      "statistics": {
        "present": 280,
        "absent": 15,
        "weekly_off": 60,
        "holiday": 15,
        "half_day": 5

        "full_name": "Alice Johnson",
        "designation": "Team Lead",
        "present_days": 24
      }
    ]

Python Example:

import requests

url = 'http://localhost:8000/api/supervisor-dashboard/team-overview/'
headers = {'Authorization': f'Bearer {supervisor_token}'}
params = {'month': 10, 'year': 2024}

response = requests.get(url, headers=headers, params=params)
data = response.json()['data']

print(f"Team Size: {data['team']['total_members']}")
print(f"Attendance: {data['attendance']['attendance_percentage']}%")
print(f"Top Performer: {data['top_performers'][0]['full_name']}")

JavaScript Example:

const params = new URLSearchParams({ month: 10, year: 2024 });

const response = await fetch(
  `http://localhost:8000/api/supervisor-dashboard/team-overview/?${params}`,
  { headers: { 'Authorization': `Bearer ${supervisorToken}` } }
);

const { data } = await response.json();
console.log('Team Overview:', data);

📅 Attendance Management

POST
/api/supervisor-dashboard/mark-team-attendance/

Mark attendance for a team member

Request Body:

{
  "employee_id": 12,
  "date": "2024-10-07",
  "status": "P"
}

Status Values:

  • P - Present
  • A - Absent
  • WO - Weekly Off
  • H - Holiday
  • HD - Half Day

Response (201 Created):

{
  "success": true,
  "message": "Attendance marked successfully",
  "data": {
    "id": 145,
    "employee": 12,
    "date": "2024-10-07",
    "status": "P"
  }
}

JavaScript Example:

const response = await fetch(
  'http://localhost:8000/api/supervisor-dashboard/mark-team-attendance/',
  {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${supervisorToken}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      employee_id: 12,
      date: '2024-10-07',
      status: 'P'
    })
  }
);

const result = await response.json();
console.log(result.message);
POST
/api/supervisor-dashboard/bulk-mark-team-attendance/

Mark attendance for multiple team members

Request Body:

{
  "date": "2024-10-07",
  "attendance_records": [
    {"employee_id": 12, "status": "P"},
    {"employee_id": 13, "status": "P"},
    {"employee_id": 14, "status": "A"}
  ]
}

Response (200 OK):

{
  "success": true,
  "message": "Bulk attendance marking completed",
  "summary": {
    "created": 2,
    "updated": 1,
    "errors": 0
  },
  "errors": null
}

Python Example:

data = {
    'date': '2024-10-07',
    'attendance_records': [
        {'employee_id': 12, 'status': 'P'},
        {'employee_id': 13, 'status': 'P'}
    ]
}

response = requests.post(
    'http://localhost:8000/api/supervisor-dashboard/bulk-mark-team-attendance/',
    headers={'Authorization': f'Bearer {supervisor_token}'},
    json=data
)

print(response.json()['summary'])

⚡ Quick Actions

GET
/api/supervisor-dashboard/today-attendance-summary/

Get today's attendance summary for quick overview

Response (200 OK):

{
  "success": true,
  "supervisor": {
    "id": 5,
    "name": "John Supervisor"
  },
  "date": "2024-10-07",
  "summary": {
    "total_team": 15,
    "present": 12,
    "absent": 1,
    "not_marked": 2
  },
  "members_status": [
    {
      "employee_id": 12,
      "employee_code": "EMP012",
      "full_name": "Alice Johnson",
      "status": "Present",
      "status_code": "P"
    },
    {
      "employee_id": 13,
      "employee_code": "EMP013",
      "full_name": "Bob Smith",
      "status": "Not Marked",
      "status_code": null
    }
  ]
}

Python Example:

response = requests.get(
    'http://localhost:8000/api/supervisor-dashboard/today-attendance-summary/',
    headers={'Authorization': f'Bearer {supervisor_token}'}
)

summary = response.json()['summary']
print(f"Present: {summary['present']}/{summary['total_team']}")
print(f"Not Marked: {summary['not_marked']}")

JavaScript Example:

const response = await fetch(
  'http://localhost:8000/api/supervisor-dashboard/today-attendance-summary/',
  { headers: { 'Authorization': `Bearer ${supervisorToken}` } }
);

const { summary, members_status } = await response.json();

// Get not marked employees
const notMarked = members_status.filter(m => !m.status_code);
console.log('Not Marked:', notMarked.map(m => m.full_name));

💡 Use Case: Morning Attendance Routine

  • Step 1: Call today-attendance-summary to see who's not marked
  • Step 2: Use bulk-mark-team-attendance to mark all present members
  • Step 3: Review the summary again to confirm all marked
  • Result: Complete team attendance marked in under 2 minutes!

🔐 Authentication

JWT Token Authentication

All Supervisor Dashboard APIs require JWT authentication with Supervisor role.

Header Format:

Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc...

Python Example:

headers = {
    'Authorization': f'Bearer {supervisor_jwt_token}',
    'Content-Type': 'application/json'
}

response = requests.get(
    'http://localhost:8000/api/supervisor-dashboard/team-overview/',
    headers=headers
)

JavaScript Example:

const headers = {
    'Authorization': `Bearer ${supervisorJwtToken}`,
    'Content-Type': 'application/json'
};

const response = await fetch(
    'http://localhost:8000/api/supervisor-dashboard/team-overview/',
    { headers }
);

⚠️ Best Practices

  • Date Format: Always use YYYY-MM-DD format
  • Team Validation: APIs automatically validate if employee belongs to supervisor's team
  • Bulk Operations: Use bulk APIs for better performance when marking multiple attendances
  • Quick Actions: Use today-attendance-summary for dashboard widgets
  • Date Ranges: Keep date ranges reasonable (max 3 months) for better performance
  • Error Handling: Always check success field in response
  • Decimal Hours: Use decimal format for overtime (3.5 = 3 hours 30 minutes)
